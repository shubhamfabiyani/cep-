# Engineering Scholarship Finder — Engineering Scholarship Portal

A professional React + Vite frontend for discovering Engineering/B.Tech scholarships.

## Run locally

1. Install Node.js 18+.
2. Extract this ZIP.
3. Open a terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown by Vite.

## Main flow

Landing page → Student Profile → Scholarship Categories → Filtered Scholarship Cards → Official Portal.

## Important

The included scholarship records are demo/seed data for the UI. Before using this as a real public scholarship service, connect the records to a verified 2026–27 scholarship database/API and re-check every deadline, income rule, amount, renewal condition, and simultaneous-scholarship rule against the official provider.
